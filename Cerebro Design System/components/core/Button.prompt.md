Action button; secondary (bordered white) is the default — primary is reserved for the single main action of a view ("Create objective", "Save").

```jsx
<Button variant="primary" icon="plus">Create objective</Button>
<Button>Cancel</Button>
<Button variant="ghost" icon="sliders-horizontal">Board controls</Button>
<Button variant="danger">Delete view</Button>
```

Sizes sm/md/lg (28/32/38). Labels are sentence-case verbs. Never two primaries side by side.
