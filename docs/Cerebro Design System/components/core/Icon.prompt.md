Lucide line icon wrapper — the only sanctioned icon path in Cerebro (no hand-rolled SVGs, no emoji).

```jsx
<Icon name="target" size={16} />
<Icon name="sparkles" size={14} color="var(--synapse-500)" />
```

Sizes 14/16/18/20. Entity glyphs live in `EntityIcon`; use `Icon` for actions & navigation (`plus`, `search`, `sliders-horizontal`, `chevron-down`, `bookmark`, `x`).
