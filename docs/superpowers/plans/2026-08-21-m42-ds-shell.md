# M42 — the shell speaks the design system, and the nav nests everything

**Driving complaint (user, 2026-08-21):** "it doesn't look like our design system
at all @docs/cerebro-ds and the nav should have tabs that open up [their] tabs in
the side nav — everything should be nested under its group like in Notion, so we
see it all there, available."

**Evidence** (side-by-side screenshots, app on :5391 vs `CerebroApp.dc.html`):

- The DS mock's sidebar is a sunken surface (`--surface-sunken`), selection is a
  cortex wash with cortex ink (`--surface-selected` + `cortex-700`), counts are
  quiet gray numbers. Ours is white, selects in gray, and hangs a filled blue
  pill on Inbox — the DS says "numbers are quiet facts."
- The mock's nav nests: the Agents group lists every agent under a Fleet head
  (paused ones dimmed, `+ New agent` at the end); Spaces expand to their
  projects. Ours shows ten flat destinations and reveals Base's rows only while
  Base is current.
- Our Agents surface runs on ALL-CAPS boxed status text ("SUCCEEDED", "WAITING
  ON YOU"), native `<select>` filters, and border-boxed rows. The DS forbids
  caps outside eyebrows, keeps native selects for dense forms only, and renders
  the roster as quiet rows with sentence-case chips and right-aligned meta.

**Doctrine unchanged:** one nav column (M37.3), labels-spend-kinds-stay, absent
is never zero, no badge counts up at you from the chrome. This milestone is
paint and geometry — no engine, no IPC, no policy.

## Slices

- **M42.1 — sidebar chrome to DS.** `--surface-sunken` sidebar (collapsed rail
  too), `rowClass` active → `--surface-selected` + `cortex-700` ink, Inbox pill
  → quiet mono count. Testids (`nav-badge`), aria (count-in-name, aria-current)
  all keep their contracts; classes only.
- **M42.2 — destinations become groups.** A `NavGroup` head row carries a
  rotating chevron (stopPropagation — expanding is not navigating); children
  render nested and are available on EVERY surface, not only while current:
  - Agents → one row per agent record (`isAgentEntry` → navigate
    `{kind:'agents', actor}`) + `New agent`.
  - Base → `KnowledgeNav`, which grows a `current` prop so it stops electing a
    default active row while another surface owns the canvas.
  - Work → mounted roots (`useRootsStore`) → `{kind:'workspace', root}`.
  - Studio → `studioProjects(entries)` → `{kind:'studio', project}`.
  - History stays a leaf (Changes/Pulse share one destination by M9.4 design).
  Open-state persisted in uiStore, default open — the ask is "we see it all
  there". Nested rows live OUTSIDE `nav-surfaces` containers (the e2e scoping
  doctrine — an agent named "Home" must never be caught by a destination spec).
- **M42.3 — the roster looks like the DS.** Rows lose their boxes: hover wash,
  icon tile, sentence-case state chip (testids/data-state unchanged), quiet
  right-aligned meta. Every absence sentence stays word-for-word.
- **M42.4 — run feed and agent page to DS.** FleetSection: native selects → DS
  `Select`, caps outcome boxes → sentence-case chips, row boxes → hairline rows.
  AgentsPage detail: icon-tile header (mock's agent page), charter before
  grants. All testids and unavailable-sentences keep their contracts.
- **M42.5 — topbar ask-bar.** "Search or ask Cerebro" placeholder + synapse
  sparkle on the ⌘K bar (the palette already has the ask row); nothing else.

## Non-goals (named so they stay deliberate)

- No icon rail: the mock predates M37.3's user-approved flatten; the NESTING is
  what the user is pointing at, not the second column.
- No global caps sweep beyond the agents surfaces and shell — logged as a
  follow-up.
- Nested agent rows say the name only; duty/paused state stays on the Agents
  surface (a fleet read in the nav is a second copy of the roster's four reads).
