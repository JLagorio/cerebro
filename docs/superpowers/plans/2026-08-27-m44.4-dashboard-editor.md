# M44.4 — Dashboard rows/cells widget editor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace `DashboardSpec`'s flat `blocks[]` with a rows/cells model (with migration), render it with per-row heights and per-widget width weights, add four own-scope widget kinds (table, board, timeline, chart) beside the surviving `view` embed and `number`, an in-canvas Edit mode with add-widget popover, widget menu, cross-row drag-and-drop, seam/row resize, per-widget filters, and a dashboard-wide Global filter.

**Architecture:** The spec becomes `{ rows: DashboardRow[]; global?: FilterGroup }` where a row holds up to 4 widgets and a dashboard up to 12 (`MAX_ROW_WIDGETS`/`MAX_DASHBOARD_WIDGETS`, toast-enforced in the pure move/add helpers). All structural edits are PURE engine functions (`addWidget`/`removeWidget`/`moveWidget`/…) so the DnD handler stays a thin adapter, exactly like `BoardView`'s tested `handleDragEnd(event, args)` pattern. Editing flows through the `onPresentationChange` prop `ViewCanvas` already owns but never forwarded to `DashboardView`. Own-scope widgets render the existing view components DIRECTLY (TableView/BoardView/TimelineView/ChartView) with locally-composed presentations — not through `resolveSurface`, which stays the `view`-embed's path. Filters compose as nested groups: `{ all: [global, widget.filter] }` layered onto already-view-filtered entries — `evaluateFilters` handles nesting and skips half-built rules by design.

**Tech Stack:** React 19, `@dnd-kit/core` (already installed; NO new dnd packages), the `ColumnResizer` paint-on-drag/persist-on-commit resize pattern, `FilterBuilder`/`FilterChips` primitives.

**Plan-level decisions (spec §4 questions this slice resolves):**
- **Q8 (3-layer filter stack):** AND across layers, by nesting: effective entries = view-filtered surface entries (unchanged upstream) → `global` → `widget.filter`, each applied with `evaluateFilters`. `wvPasses`/`match:'all'` is prototype vocabulary — the shipped contract is `FilterGroup`'s `all`/`any` nesting and the half-built-rule skip (`viewFilters.ts:487-508`), which this composition inherits for free.
- **Q9 (dnd-kit vs own primitives):** `@dnd-kit/core` as BoardView uses it — Pointer+Keyboard sensors, `useDraggable` widgets, `useDroppable` SLOT targets with globally-unique ids (`row-<id>:slot-<n>` — the registry is a Map, duplicate ids silently kill targets), drop resolution in a pure exported `handleWidgetDragEnd`. No `@dnd-kit/sortable` dependency; insertion indicators are `isOver`-painted slot elements, the repo's own inset-line style. Resize does NOT use dnd-kit — it copies `ColumnResizer`'s split `onDrag` (paint, no persist) / `onCommit` (persist once) because a widget resize writes YAML and the repo already learned that fire-on-every-move "barely worked" (`TableView.tsx:914-925`).
- **The design's 8 widget kinds collapse to 6.** Metric presets are not a kind: the add-widget popover's Metrics group mints configured `number` widgets (Count / Sum of… / Average of…) — one vocabulary, presets are UI. Horizontal bar is not a kind: it's a `chart` widget whose `ChartSpec.horizontal` is true (M44.2's flag). Final vocabulary: `view` (the surviving 9th-kind embed, per §5), `number`, `table`, `board`, `timeline`, `chart`.
- **`wide` dies with `blocks[]`.** Row structure encodes width; migration gives a legacy wide block its own row and pairs consecutive non-wide blocks two-to-a-row (the old auto-fit grid's typical shape).
- **BlocksPage shrinks.** The canvas Edit mode replaces the side-panel block editor; BlocksPage keeps only the Global-filter editor plus a pointer to canvas editing. Two parallel editors of one structure would drift.
- **Widget ids survive migration** (legacy block ids carry over verbatim) so `dashboard:${id}` collapse scopes don't reset.

function parseDashboard(raw: unknown): DashboardSpec | undefined {
  if (raw === undefined || raw === null) return undefined;
  const obj = asRecord(raw);
  // Legacy shapes (M16.28): a bare array, or { blocks: [...] } — migrated on
  // read. A wide block keeps its own row; neighbours pair up two to a row,
  // the shape the old auto-fit grid drew. Ids survive so collapse scopes hold.
  if (Array.isArray(raw) || obj.blocks !== undefined) {
    const legacy = parseLegacyBlocks(Array.isArray(raw) ? raw : obj.blocks);
    return { rows: pairLegacy(legacy) };
  }
  if (obj.rows === undefined) return undefined;
  if (!Array.isArray(obj.rows)) return { rows: [] };
  const takenRows = new Set<string>();
  const takenWidgets = new Set<string>();
  const rows: DashboardRow[] = [];
  for (const r of obj.rows) {
    const ro = asRecord(r);
    if (!Array.isArray(ro.widgets)) continue;
    const widgets: DashboardWidget[] = [];
    for (const w of ro.widgets) {
      const widget = parseWidget(w, takenWidgets, takenWidgets.size);
      if (widget !== null) widgets.push(widget);
    }
    if (widgets.length === 0) continue;
    const declared = typeof ro.id === 'string' && ro.id.trim() !== '' ? ro.id.trim() : '';
    const id = declared !== '' && !takenRows.has(declared) ? declared : nextId('row', takenRows, rows.length);
    takenRows.add(id);
    rows.push({
      id,
      ...(typeof ro.h === 'number' && Number.isFinite(ro.h)
        ? { h: Math.round(Math.min(ROW_HEIGHT_MAX, Math.max(ROW_HEIGHT_MIN, ro.h))) }
        : {}),
      widgets: widgets.slice(0, MAX_ROW_WIDGETS),
    });
  }
  const global = parseTheFilterGroupTheFileAlreadyParses(obj.global); // ← real name from this file
  return { rows, ...(global !== null && global !== undefined ? { global } : {}) };
}
```

function pairLegacy(blocks: { widget: DashboardWidget; wide: boolean }[]): DashboardRow[] {
  const rows: DashboardRow[] = [];
  let buffer: DashboardWidget[] = [];
  const flush = () => {
    if (buffer.length > 0) rows.push({ id: `row-${rows.length + 1}`, widgets: buffer });
    buffer = [];
  };
  for (const { widget, wide } of blocks) {
    if (wide) {
      flush();
      rows.push({ id: `row-${rows.length + 1}`, widgets: [widget] });
    } else {
      buffer.push(widget);
      if (buffer.length === 2) flush();
    }
  }
  flush();
  return rows;
}

/** The rows an own-scope widget measures: the dashboard's already-view-
 * filtered entries, through the Global filter, through the widget's own —
 * AND semantics, and a half-built rule filters nothing (M16.29's contract). */
export function widgetEntries(
  entries: Entry[],
  spec: DashboardSpec,
  widget: DashboardWidget,
  schema: Schema,
): Entry[] {
  const layers = [spec.global, widget.filter].filter((f): f is FilterGroup => f !== undefined);
  if (layers.length === 0) return entries;
  return entries.filter((e) => layers.every((g) => evaluateFilters(e, g, schema)));
}

export type DashboardEdit = { ok: true; spec: DashboardSpec } | { ok: false; reason: string };

const ROW_FULL = 'A row holds at most four widgets';
const DASHBOARD_FULL = 'A dashboard holds at most twelve widgets';

export function widgetCount(spec: DashboardSpec): number {
  return spec.rows.reduce((n, r) => n + r.widgets.length, 0);
}
```

Slot id scheme: `slot:<rowId>:<index>` (0..widgets.length) plus one `slot:new-row` trailing the last row — globally unique by construction (the dnd-kit-registry-is-a-Map lesson). Pure handler exported:

```ts
export function handleWidgetDragEnd(
  event: DragEndEvent,
  args: { spec: DashboardSpec; commit: (next: DashboardSpec) => void; toast: (msg: string) => void },
): void {
  const over = event.over === null ? null : String(event.over.id);
  if (over === null || !over.startsWith('slot:')) return;
  const id = String(event.active.id);
  const edit =
    over === 'slot:new-row'
      ? moveToEnd(args.spec, id) // moveWidget onto a fresh trailing row — add this pure editor in engine/dashboard.ts (3 lines over addWidget/removeWidget)
      : moveWidget(args.spec, id, over.split(':')[1], Number(over.split(':')[2]));
  if (!edit.ok) {
    args.toast(edit.reason);
    return;
  }
  if (sameStructure(edit.spec, args.spec)) return; // identity drop — compare row/widget id matrices
  args.commit(edit.spec);
}
```
