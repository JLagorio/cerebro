### M58.1b Who last changed a page, and what a run wrote, in words

- **What:** .1 records who wrote what, and nothing reads it back. "An external edit reads unattributed" and "NULL renders not recorded" need a read model and a surface. `writes_booked` tells "wrote nothing" from "partial" and "not recorded" (CV-05). .3 reuses `run_writes`.
- **Files:** `src-tauri/src/runtime/{write_log.rs (new), mod.rs, fleet.rs}`, `src-tauri/src/lib.rs`, `src/engine/attribution{,.test}.ts` (new), `src/lib/{ipc,ipcContract.test,mockIpc,mockIpc.test,demoOperational}.ts`, `src/detail/{LastChange,LastChange.test}.tsx` (new), `src/detail/DocSidePanel.tsx`, `src/status/{RunDetailPanel,RunDetailPanel.test,FleetSection.test,AgentRunHistory.test}.tsx`, `src/pages/AgentsPage.test.tsx`, `e2e/attribution.spec.ts` (new).
- **Approach:**
  - **Read model** (`runtime/write_log.rs`, SELECT-only on `&ReadOnly`). `page_attribution(ro, vault_id, path, current_hash)`: Recorded {kind, actor (None: not recorded), run_id, approved_by, at} when the newest content row's hash is the file's; Unattributed {last} when the bytes changed after it; NotRecorded with no row; Knowledge for a bundle path changed outside a door. A rename into the path is followed back, at most 8 hops. `run_writes(ro, run_id)`: Recorded(rows) when `runs.writes_booked = 1` (empty: wrote nothing), Partial(rows) when 2 (the shell may have written elsewhere), else NotRecorded.
  - **Commands.** lib.rs `page_attribution(vault, path)` resolves through `landing_path` (None: NotRecorded), hashes the bytes itself and opens ReadOnly. `RunDetail` gains `wrote: RunWrites`.
  - **Words** (`engine/attribution.ts`, pure). `writerWords`: `human:me` reads "You", anything else goes through `actorLabel`, and NULL reads "not recorded", never actorLabel's "unattributed", which here means changed outside Cerebro. Lines in Appendix A.
  - **Surfaces.** `LastChange.tsx` (`last-change`) tops the Info tab on every page, agent pages included. It fetches keyed by path and `entry.hash`; a failed read is `section-unavailable`. RunDetailPanel gains Pages written (`run-detail-pages`): non-knowledge paths open their page, and bundle paths stay in its Knowledge section. ## Risks

- **One signature pass** (.1): about 100 call sites, many in tests (the ledger writers' included), across files M53–M70 also edited. One commit; re-read each hot file first.
- **index.lock** (.3): every index writer takes the repo lock, and reads run with `GIT_OPTIONAL_LOCKS=0`, which re-stats files on large repos. gpg-signing configs can hit the 30 s deadline, and a merge in progress refuses the partial commit (unavailable).
- **Supervised git** (.3): from a dev terminal, an ssh host-key or passphrase prompt stalls to the deadline and reads as a timeout; accept the key in a terminal first. Packaged builds have no terminal.
- **Shell writes bypass `vault_writes`:** the changeset names the run's own Write and Edit paths from the fold, and it and run detail say shell changes aren't recorded (`writes_booked = 2`). `live_run_wrote` can't see them either; Restore's `expect` still refuses a racing write.
- **`vault_writes` growth:** coalescing (.1) slows it; retention comes later. The rebuild copies the whole table (unbounded since M49.10) in one transaction, met by the migration kill points on CI Linux.
- **Two records, two destinies:** concept writes now have an operational row beside their ledger event. `vault_writes` says who touched the file; the ledger says what is believed (CV-06).
- **What attribution can't say:** inside one actor's 5-minute burst, only its first and last times show. Review-applied writes (M57.4c) and reconcile projections aren't run-owned, so they commit with the next checkpoint and read "unattributed" in History.
