## Risks

- **Size:** 6 L + 2 M ≈ 7 L, more than twice the roadmap. Seams if a part outgrows L: .1's ConceptBody wiring, .2's elision, .2b's report, .3's clipboard and formula bar, .3b's Ask, .4's CSV path.
- **Old evaluator** (a roadmap risk): 0.8.3 predates upstream's new one; Macro measured one model at 8 minutes against under 2 s. The caps and the spike bound it; .4's saved-value check names cells that differ from Excel. A newer pin needs a matched release pair, never a git revision.
- **Stack:** the evaluator recurses through references, and an overflow aborts the app (catch_unwind can't catch one). Rust evaluates only on the 64 MiB engine thread (the token and .2's rail), sized at the 10,000-cell snake; the wasm overflows sooner and gives the stopped words, so parity cases stay shallow.
- **Results and time:** the caps bound inputs, not results. A computed array size (`=SEQUENCE(A1)`, `=A:A+1`) can still fill memory past any literal check; the deadline frees the caller, not the memory, and an abandoned engine thread runs to its end. An allocation failure aborts.
- **Determinism:** 0.8.3 has no seed, its fixed clock (`mock_time`) serves Rust tests only, and native and wasm libm can differ in the last digit. The shared goldens avoid all three; Rust-only tests pin NOW and TODAY.
- **Excel input rules:** 007 reads 7, `- item` becomes a formula, dates parse. The docblock says so; `'` keeps text.
- **Fence grammar:** ConceptBody now honors CommonMark backtick/tilde marker identity and minimum closing length. The editor carrier preserves source, including trailing blank lines that BlockNote otherwise trims, and lengthens a backtick delimiter around an embedded backtick line. Agent/grid writers additionally refuse delimiter-looking values and quote a lone `---`; their round trip checks what the rules miss.
- **BlockNote:** `meta.selectable: false` relies on internals (blocks.test pins it; e2e and the packaged check prove it). BlockNote hoists `source` onto the DOM (trap 4). jsdom lies about custom blocks (traps 1, 4): specs use testids and Playwright geometry.
- **Undo:** the grid re-scrolls itself after ProseMirror's undo. ⌘Z in page text can undo a grid step: one history, by design.
- **Twins:** Rust and TS writers must match byte for byte (sheet-edit-cases), and .3 and .4 must reuse them. The `bodies` cases are Rust-only until .2b, and the registry says so.
- **Canonical re-encoding** reshapes a hand-formatted fence's untouched rows once, on its first edit.
- **Locks:** edit_sheet plans and evaluates twice under the page's lock; the caps and the engine deadline bound the wait. M57.4c's 256 KiB queue cap refuses a huge unattended batch in its own words.
- **Deletes:** clearing cells is a delete in scope, unrecoverable without git (the M55 Q9 class); M58.4's Restore helps.
- **Hostile workbooks:** zip 0.6 inflates without a bound, so .4 reads every part bounded first through M66.7's zip; refusing duplicate names narrows zip-version disagreements. An allocation failure would still abort. Upstream unwraps become refusals on the engine thread, logged by M53.24's hook.
