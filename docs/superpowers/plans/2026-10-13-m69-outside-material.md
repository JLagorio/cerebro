## Appendix A — artifacts and data

**`shared/import/sources.v1.json`** (.3; v2 in .3b). Two-space JSON, LF, one final newline, no BOM, non-ASCII as `\u` escapes.

- **Header:** `format` 1, `artifact_version`, `rule_version` `sources/<commit date>`, `about`.
- **Families:** `cache {stamped_by "cache_source", keys [source_id, source_kind, source_url, fetched_at, stale_after, generated], kinds [issue, web]}` · `import {stamped_by "the import writer", keys [source_system, source_record_id, source_url, imported_at, imported_by, import_method, import_hash], methods [captured, agent_composed]}`. Only `source_url` is shared.
- **Systems,** sorted:
  - `ics {label "Calendar file", record "a digest of the event UID and its RECURRENCE-ID", id_steps [trim, require_printable {max 1100}, sha256_hex {domain "cerebro-ics-v1"}]}`
  - `linear {label "Linear", record "the issue UUID, never its identifier", id_steps [trim, ascii_lower, require_uuid]}`
  - `notion {label "Notion", record "the page id, from an id or a link", id_steps [trim, drop_query_and_fragment, trim_trailing_slashes, last_segment, remove {chars "-"}, ascii_lower, take_last {count 32}, require_hex {length 32}]}`
- **Steps** (closed, each with its words): trim (ASCII tab, LF, FF, CR and space at both ends); drop_query_and_fragment (cut at the first `?` or `#`); trim_trailing_slashes; last_segment (after the last `/`); remove {chars}; ascii_lower (A–Z only); take_last {count} (code points); require_hex {length} (0–9, a–f); require_uuid (8-4-4-4-12 of 0–9 and a–f); require_printable {max} (non-empty, at most max code points, no U+0000–U+001F or U+007F); sha256_hex {domain} (sha256 hex of the domain, a NUL, the text).
- **Stamp:** `order` the import keys as listed; `value` `json_string`; `volatile` [imported_at, imported_by, import_hash]; `optional` [source_url, import_method]. `import_hash {domain "cerebro-import-v1"}`: sha256 hex of the domain, a NUL, then the composed bytes with each volatile value written as `""`.
- **Compose:** content opens `---` + LF, holds no CR, and closes at the first LF + `---` + LF from offset 3 (an empty block allowed). Its YAML is a mapping or nothing and sets no key of either family; a string `type:` may not equal a refused type (trimmed, ASCII case-insensitive). Stamps go just before the closing fence, one `key: <JSON string>` line each, in order, optional ones only when set. A stored hash reads only when each volatile key has one `key: "…"` line and `import_hash` is 64 lowercase hex.
- **Refused:** types [Agent, Collection, Skill, Type]; roots [knowledge/, sources/].
- **Outcomes:** created "new page" · replaced "updated in place" · unchanged "already imported, nothing new" · kept "left as it is" · duplicate "listed twice in this import". **Kept reasons:** changed_since_import "changed since it was imported" · stamp_unreadable "its import stamp no longer reads as written".
- **Messages:**
  - unknown_system: "{system} is not an import source Cerebro knows ({systems})."
  - bad_record_id: "{input} is not a {label} id ({record})."
  - bad_url: "{input} is not an http or https address."
  - bad_shape: "An import's content opens with its frontmatter between --- lines and uses LF line endings."
  - stamped_key: "An import's content may not set {keys}: Cerebro stamps where a page came from."
  - refused_type: "An import never writes a type: {type} page."
  - bad_path: "{path} is not a .md page outside knowledge/ and sources/, so no import lands there."
  - path_twice: "{path} is planned twice in one batch."
  - stamp_refusal (v2): "Agent writes may not add, change or remove {keys}: they record where a page came from, and only Cerebro's import and fetch writers set them. Ask the person to re-import or re-fetch instead."
- **Cases:** `record_ids`, `import_hashes`, `stamps`; v2 adds `agent_guard` and `stamp_guard`.
