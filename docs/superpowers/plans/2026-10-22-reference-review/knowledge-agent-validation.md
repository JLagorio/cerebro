# Independent validation: agents, knowledge and retrieval

Reviewed 2026-10-22 against the current working tree and the five local reference dossiers. This is a source audit of CP05–CP10 in the [strengthening plan](../2026-10-22-reference-strengthening-plan.md), not implementation, a live CLI experiment, or a fresh test pass. Existing staged work and reference repositories were left unchanged.

The proposed direction is sound: expose and evaluate Cerebro's existing guarantees before expanding autonomy. The strongest immediate additions are exact-passage navigation, outcome/relevance fixtures, truthful partial-run explanations and an inspector for existing evidence. Full isolated rehearsal is a larger conditional engineering project. It must not become a prerequisite for the useful deterministic trigger preview.

## CP05: deliver the location contract before citation polish

[search.rs](../../../../src-tauri/src/search.rs), lines 160–176, defines `ExcerptAt::Line` and `ExcerptAt::Field`; line numbers count the body exposed by `get_note`, while highlight ranges are Rust byte offsets. However, `VaultHit` at lines 892–900 contains only path, title, type and display parts. [QuickOpen.tsx](../../../../src/app/QuickOpen.tsx), lines 353–371, therefore opens only the path. This is a backend/IPC/navigation gap, not merely a missing click handler.

Morrow's [PageEditor.tsx](../../../examples/Morrow-main/src/app/editor/PageEditor.tsx), lines 230–248, searches for the first lowercased text occurrence, focuses it, selects it and consumes the request. That demonstrates continuity, but does not establish correct repeated-occurrence or stale-version behavior. Macro's typed node/PDF citations are a stronger location model, but persistent editor IDs alone do not establish portable Markdown identity.

The minimum useful slice is one source-versioned Markdown/property location returned by the existing search API and revealed once through the existing editor owner. Define body-line versus source-file-line numbering and UTF-8/UTF-16 conversion explicitly. Preserve the selected occurrence through display normalization: a visible wikilink label is not necessarily the underlying bytes. Test repeated passages, modified source, projected titles, collapsed content, property matches and already-open panes. Passive reveal must not replace the person's editing selection. Assistant citations can follow, only for locations actually supplied by a trusted read result; a model's invented reference cannot confer a verified badge.

## CP06: distinguish protocol correctness, retrieval adequacy and model outcomes

[eval/mod.rs](../../../../src-tauri/src/eval/mod.rs), lines 1–65, already describes synthetic adversarial journeys crossing assembly, policy, contradiction, coverage and review boundaries. It explicitly avoids duplicating module acceptance tests. [sanitize.ts](../../../../scripts/cli-record/sanitize.ts), lines 1–29, preserves real CLI framing through a deliberately stricter sanitizer. Calling Cerebro unevaluated would be false.

Activepieces's [agent-eval.test.ts](../../../examples/activepieces-main/packages/server/worker/test/lib/agent-eval/agent-eval.test.ts), lines 9–58, distinguishes regression fixtures from capability targets, repeats live trials and records judge agreement. It also skips without a provider key. Adapt the evaluation shape through the user's own Claude Code authentication; do not introduce that credential architecture. Its injection fixture combines prohibited tool arguments with task-quality judgment. The fixture's description still says “capability” while its actual `kind` is `regression`: executable classification outranks stale prose.

Begin with six end-to-end fixtures: supported answer, counterevidence, self-verification refusal, stale target, unattended ask-first write and imported-content injection. Each should check durable files/receipts, forbidden effects and visible outcome, with a negative control that breaks a real rule. Recorded replay proves interpretation of recorded behavior; it cannot establish that today's model will choose the same tools. Keep live outcome results separate, repeated, versioned and explicitly skipped when not run.

Also separate three retrieval populations: page-text BM25, entity/alias/graph expansion, and evidence assembly. [retrieval/mod.rs](../../../../src-tauri/src/retrieval/mod.rs), lines 3–33, explicitly excludes a paraphrase with no shared entity, alias or relation and requires pure replay for precondition checking. A pooled relevance score can hide that boundary. Measure source recall at each production cutoff, inaccessible-source leakage, counterevidence coverage and answer support independently. An embedding experiment must preserve replayable candidate identity; a mutable vector service is not a drop-in replacement for the guarded graph retriever.

## CP07: preserve the distinction between historical configuration and evidence

[runtime/schema.rs](../../../../src-tauri/src/runtime/schema.rs), lines 1282–1388, already retains causes, CLI session IDs and a queued write's `grant_json`, canonical input hash and target hash. [fleet.rs](../../../../src-tauri/src/runtime/fleet.rs), lines 59–150, exposes lineage, observed usage/model facts and assembly metrics. These facts should be reused, not duplicated into a second run record.

A bounded execution manifest can add effective instruction/skill identities, effective grants, policy identity and observed environment. Requested model and observed model must remain distinct; resuming a CLI session may introduce earlier context or configuration that a new dispatch manifest cannot reconstruct. User-level CLI settings and connector inheritance further limit any claim of exact reproducibility. A hash proves identity when the bytes are available; it does not recover missing historical instructions or freeze a remote service's behavior.

The existing working-memory manifest is a different object. [assembly/manifest.rs](../../../../src-tauri/src/assembly/manifest.rs), lines 263–320 and 570–580, records assertion/belief revision items, source IDs, content hashes, limits, retrieval intents and counterevidence. [assembly/corpus.rs](../../../../src-tauri/src/assembly/corpus.rs), lines 13–27, deliberately excludes raw source prose and renders committed typed claims. [assembly/ask.rs](../../../../src-tauri/src/assembly/ask.rs), lines 90–110, reads one ledger snapshot; [assembly/store.rs](../../../../src-tauri/src/assembly/store.rs), lines 4–23, keeps an immutable operational receipt.

Accordingly, “Why this evidence” should first inspect an actual assembly: which assertions/revisions and supporting source identities were selected, what intents were exhausted or blocked, and how counterevidence was handled. It must not imply that these records enumerate every page seen by ordinary chat. Nor does omission mean “irrelevant”: unavailable, capped, unsearched and outside-scope are different facts. Reopening source content requires current access checks and honest changed/missing-source handling.

The roadmap's D4 retains per-turn CLI transport; D5 allows a collapsed read-only fold of the CLI-owned transcript, stored nowhere anew ([roadmap](../2026-10-12-macro-port-roadmap.md), lines 25–26). Do not create a transcript archive to implement configuration comparison. [transcript.rs](../../../../src-tauri/src/agent/transcript.rs), lines 19–25, reads actual `cleanupPeriodDays`; 30 days is a default, not an unconditional retention guarantee. Historical manifests and child views must respect the disclosed retention and purge boundaries.

## CP08: preview is immediately useful; isolation requires its own proof

Activepieces's [test-execution-context.ts](../../../examples/activepieces-main/packages/server/engine/src/lib/handler/context/test-execution-context.ts), lines 18–98, seeds previous steps with sample output; it even constructs an engine API context and resolves inputs. This is evidence for sample-driven inspection, not a no-side-effects sandbox.

First expose deterministic trigger preview using the actual matching and admission rules, injected clock and a coherent snapshot of pause/budget/scope facts. Production admission currently writes operational state; calling it then rolling back is not a clean read-only preview design. Extract/reuse pure decision logic and shared cases. Report “would match under these observed conditions” and whether a model condition remains unevaluated. Do not reserve a lease, consume deduplication identity, create wakes/followups or imply future budget availability.

Full rehearsal needs a separate boundary review. [agent/mod.rs](../../../../src-tauri/src/agent/mod.rs), lines 1686–1770, shows permission flags, inherited user settings and conditional strict MCP configuration. [cli_writes.rs](../../../../src-tauri/src/agent/cli_writes.rs), lines 3–20, expressly says CLI Write/Edit bypass Cerebro's writer doors and `vault_writes`. A disposable cwd or an isolated MCP write sink therefore does not itself prove that production files, settings, hooks, connectors, other tools or network effects are inaccessible.

Require a demonstrated process/config/filesystem/tool boundary, explicitly controlled connector reach and bounded scheduler sinks before promising no production effects. A read-only instruction experiment is a legitimate interim feature only when its actual reachable tools are read-only and its limitations are visible. Keep model network access and permitted observations distinct from prohibited outside mutations. If isolation cannot be proven on supported CLI versions, ship preview and defer full rehearsal rather than weaken the claim.

## CP09–CP10: show the evidence available without promoting its authority

[dispatch.rs](../../../../src-tauri/src/runtime/dispatch.rs), lines 1251–1274, recovers expired leases as abandoned with unknown usage and requeues work. [pending_writes.rs](../../../../src-tauri/src/runtime/pending_writes.rs), lines 363–383, preserves interrupted-apply semantics. [AiPanel.tsx](../../../../src/agent/AiPanel.tsx), lines 1142–1151, retries by asking the previous question again. These support clearer recovery explanations, not an exactly-once replay promise. Distinguish receipted Cerebro writes, observed completed CLI writes, inferred changes and unknown foreign effects. No receipt is not proof that nothing changed.

The child-trace gap is definite: [fold.rs](../../../../src-tauri/src/agent/fold.rs), lines 413–417 and 515–519, ignores sidechain/parent-tool events. Macro's [subagent.rs](../../../examples/macro-main/crates/folds/agent_fold/src/domain/fold/subagent.rs), lines 10–62, demonstrates explicit parent linkage and an orphan fallback. Extend Cerebro's existing fold and reducer under CV-26/27 using sanitized real recordings, strict child/depth/byte limits and partial-state labels. Trace visibility must not silently alter write attribution, changeset commits, connector capture or approval authority. A child cannot answer a human decision.

For connections, [links.ts](../../../../src/engine/links.ts), lines 46–81, already memoizes backlinks, and [DocSidePanel.tsx](../../../../src/detail/DocSidePanel.tsx), lines 87–112, renders them. Add bounded on-demand snippets before a graph. Mention search must use filename/link resolution rules, disclose caps, and avoid a full-body render-time scan. A suggested link is not evidence support, contradiction or verification.

[knowledge.rs](../../../../src-tauri/src/knowledge.rs), lines 11–25, closes ordinary agent writers around human verification; [ConceptReviewBar.tsx](../../../../src/knowledge/ConceptReviewBar.tsx), lines 98–120, binds Verify to the viewed bytes and leaves agent-owned recheck dates untouched. Neither graph similarity, flashcard recall, model judgment, memory nor a successful rehearsal can substitute for that act. Morrow and Thought Desk offer discovery/learning patterns, not stronger epistemic guarantees.

## Main-plan corrections and smallest valuable sequence

1. Describe the strength as **guarded Cerebro mutation APIs**, acknowledging approved direct CLI writes and their partially observed child path. Avoid a universal “one mutation path” claim.
2. Scope CP07 evidence inspection to actual ledger assemblies; stage general chat context capture separately. Reject exact replay claims and implicit transcript retention.
3. Split CP08 preview from conditional full isolation, with separate acceptance and sizing. Put configuration comparison and six outcome fixtures ahead of full rehearsal.
4. Ship one exact search landing, one assembly inspector and one truthful partial-run explanation before broad citation carriers, graphs or automated continuation.
5. Preserve Tolaria's smaller workflow improvements in the main queue: chat currently maps a failed CLI probe to “not installed” at `AiPanel.tsx:1010–1014`; versioned human/agent help generated from one source can reduce setup errors without increasing autonomy. Test help examples against shipped tools to prevent documentation drift.

Reject a second scheduler, provider keys, automatic external-effect replay, persistent transcript mirroring and confidence scores that collapse review/support/freshness into one number. These are not required to realize the reference repositories' most useful lessons.
