## Important

The document line references in these findings identify the reviewed pre-amendment packet. The final authoring disposition below records where they were corrected. Source line references identify the inspected application/reference excerpts.

1. **Creation identity conflates plain pages and sheet pages.** M94 spec `docs/superpowers/specs/2026-10-23-m94-ui-polish-and-journeys-design.md:180` defines page identity solely by folder; lines 200–203 canonicalize that into the singleton draft/submission key. Actual `src/app/CreateLauncher.tsx:194` and `:196` open the same dialog in two modes; `src/app/CreateMenu.tsx:62`–`:68` writes materially different bodies based on `sheet`. Resuming the same key from the other launcher could create the wrong artifact. **Fix:** freeze an immutable creation recipe/variant in the request, draft key and submission snapshot; never derive it from the currently mounted dialog. Explicitly scope the first stage to plain pages/sheets and ordinary records, or separately enumerate every other launcher flow. Add page→close→sheet and sheet→close→page cases, pending variant isolation, and create-more variant retention. Parent accepted; amend M94.4/spec in authoring stage.

2. **Precise source versions require changing the corpus producer, which M97.1 omits.** M97 spec `:90` hashes complete raw file bytes; M97 plan `:51`–`:54` excludes `src-tauri/src/vault/corpus.rs`. Actual `CorpusText` retains only capped body/capped (`src-tauri/src/vault/corpus.rs:41`–`:48`), while entry/body are correctly derived from one read (`:169`–`:182`) and raw content is discarded by `text_of` (`:227`–`:251`). `search.rs:1049` rederives display from a line, and `:1101` emits only path/title/parts. A second file read to add a hash can label an old excerpt with a new version. **Fix:** compute raw full-file SHA-256 and source-body offset/carrier facts at the same read as entry/body; retain them in cached snapshots, carry raw occurrence offsets before display normalization, and key path/hash/range together. Add outside-edit-between-ranking-and-return, metadata-only edit, capped-body, CRLF and unsupported-carrier regressions, plus unchanged-file read-count proof. Parent accepted; amend M97.1/spec.

3. **Search return lacks a concrete owner for transient Quick Open and reused editors.** M97 spec `:44`–`:45` promises query/selection/scroll return; plan `:74`–`:83` describes per-visit reveal but no exact source-open/return API. Actual Quick Open unmounts on close (`src/app/QuickOpen.tsx:91`–`:94`), owns query/index locally (`:115`–`:123`), closes before opening (`:136`–`:153`), and `useOpenPath.ts:109`–`:115` can reuse a held editor without creating a destination visit. Record peek also differs from full-page history (`:154`–`:175`). **Fix:** define a session-only origin snapshot, explicit return/reopen behavior for Quick Open, request attachment to the actual editor holder/peek, last-request-wins and cancellation rules, and M92 canvas-safe handling. Test query/category/expanded-results/index/list-scroll restoration; two rapid source requests; holder reused in another pane; peek promotion; parked destination; deleted origin; typing elsewhere. Parent accepted; amend M97.2 and M94 cross-reference.

4. **Exact backlink landing cannot be implemented by enriching the deduplicated index alone.** M97 spec `:151` says backlink rows open the recorded occurrence; plan `:124`–`:134` names the current links index and mention producer. Actual `src/engine/links.ts:49`–`:73` intentionally stores one body backlink per source/target with only entry/via; raw link extraction deduplicates too (`src-tauri/src/vault/parse.rs:115`). Morrow does retain block contexts (`docs/examples/Morrow-main/src/core/links.ts:17`–`:45`) but its row still opens the page (`.../components/PageView.tsx:425`), so it is no proof of exact landing. **Fix:** retain the lightweight index as navigation summary; add a bounded on-demand Rust occurrence query against raw corpus bytes using the shared resolver. Define occurrence ID, source hash, deterministic order, cursor snapshot/scope identity and stale-cursor result. Test repeated links, relation fragments, duplicate titles, edits/deletes between pages and revoked scope. Parent accepted; amend M97.5/spec.

5. **Descriptor text is currently misclassified as a vault source.** M91 implementation record `docs/superpowers/plans/2026-10-23-m91-implementation-record.md:154` flags this. Actual `src/agent/elements/decisionsSources.ts:58`–`:60` falls back to `kind:'vault'` even for scope prose or missing paths; Knowledge forwards this (`src/knowledge/KnowledgePanel.tsx:175`–`:180`), and the presentation draws a file icon (`src/components/ai/Sources.tsx:134`–`:149`). M94.8/M97.4 do not explicitly assign the semantic repair. **Fix:** represent resolved local path, safe external URL, unresolved local reference and scope/description separately in the adapter. Descriptors remain ordinary text with no file semantics or source-open request; missing paths say missing. Preserve numbered citations and human-only Verify. Add scope prose, missing local page, unsafe scheme and real vault page cases. Parent accepted; amend M97.4/spec with M94 consumer boundary.

6. **Agent grants still collapse an unavailable connector list into an empty list.** `src/library/AgentProperties.tsx:103` initializes `[]`; `:106`–`:116` explicitly justifies and swallows a failed read. Existing connector-derived tool choices depend on this list (`:815`–`:838`). M94.7 maps AgentPage, and M94.8 maps ConnectorSettings, leaving the Agent's own grant-editor read outside the concrete repair map despite UX-09/10. **Fix:** assign `AgentProperties` local loading/ready/unavailable read state and Retry under M94.8. Keep grant drafts and existing connector/tool identifiers on read failure, suppress false “none enabled” claims, and leave execution fail-closed. Add failed read then Retry, vault-switch stale response, and open Tools draft preservation cases. Reported to parent; amend narrow ownership if accepted.

7. **Evidence roles need an event-level projection contract before inspection.** M97 spec `:80`–`:84` declares one role per `EvidenceRef` but does not say how multiple observations survive source deduplication or which producer may assert supporting. Existing `src/engine/ai/sources.ts:26`–`:54` keeps first `via` when a URL is searched, fetched and cited later; `turnSources.ts:29`–`:36` feeds results/read calls; Sources defaults to “Used” (`Sources.tsx:31`–`:34`). Compact M91/M92 source lists cannot establish the new evidence distinctions. **Fix:** define source identity separately from append-only role observations carrying run/attempt/tool/turn or assembly-item identity; preserve search→fetch→citation roles and failed read status. “Supporting” must identify an explicit claim/basis judgment, never be inferred from mention/read. Keep existing compact lists and M92 rail ownership, derive inspector from real CHAT/assembly producers, and label legacy coverage. Test search-only, failed fetch, search→fetch→cite, and cited-without-read. Reported to parent; add to M97.4 contract if accepted.

## Eight adopted/rejected lessons from actual references

1. **Adopt measured content edges, not a copied width number.** Morrow `src/app/styles/app.css:722`–`:730` declares 720px content plus 112px horizontal padding and a wide mode. Thought Desk `src/lib/components/PageView.svelte:153`–`:161` separately accounts for width/padding. M94's resolved-prose comparison is the right adaptation; retain Cerebro's full-width embeds and existing outer-width baseline.
2. **Adopt a quiet document anatomy.** Morrow `PageView.tsx:187`–`:245` places title, tags, row properties, body and backlinks in one article. Thought Desk `PageView.svelte:115`–`:146` does the same with row properties and optional empty-page starters. Keep Cerebro's title→properties→tabs→body contract and progressive disclosure. An optional starter is a later product choice, not required for polished geometry.
3. **Reject their second title writer.** Morrow `PageView.tsx:187` and Thought Desk `PageView.svelte:56`–`:65` write title separately from body. Cerebro's first-H1 projection/sole editor is an established safety/undo invariant; copying appearance does not justify replacing it.
4. **Adopt hover disclosure that also responds to focus.** Thought Desk `PageView.svelte:201`–`:213` reveals tools on hover and focus-within. Morrow `app.css:1754`–`:1755` uses the same pattern. M94 should measure keyboard discoverability and meaningful focus, while keeping consequential decisions always reachable.
5. **Adopt visible destination and parent precedence in creation; reject silent resets.** Plane `components/issues/issue-modal/base.tsx:85`–`:122` resolves active project from explicit data before route/default, and `modal.tsx:42`–`:45` seeds related cycle/module. This supports Cerebro's explicit In/database/host sentence and host-over-group rule. Plane `form.tsx:162`–`:172` resets fields on project change; Cerebro should retain explicit draft transfer/recovery instead.
6. **Adopt explicit peek/full-page controls and save status; preserve Cerebro return ownership.** Plane `peek-overview/header.tsx:39`–`:58` exposes modes, `:177`–`:179` full-page navigation and `:203`–`:204` update state. Use the discoverable actions, but keep Cerebro's one-editor-per-file, visit state, four panes and current navigation API.
7. **Adopt on-demand mentions with context, reject guessed passage highlighting.** Morrow `PageView.tsx:373`–`:407` computes mention results only on request. Its `PageEditor.tsx:230`–`:247` selects the first case-insensitive textual match, and `core/links.ts:86`–`:110` uses current-title text matching. M97's versioned raw ranges, unique relocation, shared link resolution and explicit changed/unsupported states are materially safer adaptations.
8. **Reject reference-edition parity assumptions and broad machinery copying.** Plane preview `issue-modal/provider.tsx:37`–`:54` includes no-op template/property/create-subitem handlers. Source can establish its UI seams but cannot certify working edition behavior. Its page root `pages/editor/page-root.tsx:158`–`:205` cleanly separates toolbar/body/navigation/version interfaces; adapt that responsibility boundary while preserving Cerebro's full-height one-panel slot, rather than importing collaboration/storage/editor architecture.
