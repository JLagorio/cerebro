## Top findings

1. **Hover/press are translucent state layers, and variants set component-scoped vars.** AFFiNE's Button draws hover as a `::before` overlay of `layer/background/hoverOverlay`; `[data-variant]`/`[data-size]` only assign CSS vars. Cerebro paints 276 opaque `hover:bg-n-*` washes, patches 27 grounds with local `color-mix` (`src/app/shell.css:57-63`: "hover fill … all but vanished"), and re-skins `.cb-btn-primary` state by state (`src/detail/inspector.css:142-160`). → **M94.2 role sheet, M94.3 migration.**
2. **Floating surfaces need their own elevation role.** AFFiNE menus/popovers/modals take `overlayPanel` + a role shadow, distinct from the page in both themes. Cerebro's Menu, Select, Dialog, HoverCard, Toast and DatePicker fill `--n-0`, which in dark IS `--surface-app` (#242528); `--surface-raised` is unused by them; 5 shadows are light-only literals. → **M94.2/M94.3 (VS07, VS10).**
3. **One menu item, two hosts.** AFFiNE's `MenuItem` renders in a dropdown or a right-click menu via one context. Cerebro's `ContextMenu` is a second, thinner menu used by 10 surfaces (no disabled/separator/check/submenu, literal shadow), and it never registers in `layers.ts`, so the keymap's `hasModalLayers()` gate cannot see it. → **M94.5 (PJ08).**
4. **The useful part of their docs is the primitive matrix.** Stories show variant × size × state with a light/dark toolbar, but CI never runs them and the component package has 2 spec files. Cerebro tests far more but has no primitive matrix, which VS07's "montage reads as one family" needs. → lab `?specimen=` mode, no Storybook. **M94.2/M94.9.**
5. **Loading is a surface state with geometry.** AFFiNE ships `Skeleton`, a skeleton per list surface, and an editor loader that escalates to timeout copy + Reload. Cerebro loading is a text line, and loading is not one of CV-44's preset states. → **M94.8.**
6. **Don't import the weak half.** Confirm closes on a rejected `onConfirm` and autofocuses destructive confirms (about 70 confirm sites, 1 opt-out). Notification actions fire and forget. InlineEdit's Escape commits. The toast has no live region, only 2 files honour reduced motion, and v1/v2 tokens coexist (about 2.9k vs 1.4k call sites). Cerebro's CV-03/CV-25/CV-28 rules and motion tokens are already ahead.
7. **Custom theming exists but is unguarded.** Any CSS var can be overridden per mode, saved as a map and written inline on `<html>`, behind a feature flag and with no contrast check. Any Cerebro version needs an owner call first (see Owner questions).

### AFN3-01/02 — Button as vars plus a state layer

- AFFiNE flow: `button.tsx` writes `data-variant`, `data-size`, `data-disabled`, `data-loading`, `data-no-hover`. `button.css.ts` reads `bgVar/textVar/iconColorVar/borderColorVar/hVar/paddingVar` in one base rule, and size/variant selectors only assign vars. The `::before` overlay toggles opacity. The focus ring is `:focus-visible::after` `0 0 0 1px primaryBorder`.
- Cerebro shape: `.cb-btn{background:var(--btn-bg);color:var(--btn-fg);border-color:var(--btn-border)}`, then `.cb-btn::before{background:var(--state-hover);opacity:0;transition:opacity var(--motion-hover)}`, with `:hover` → opacity 1 and `:active` → `--state-press`. Variants (`primary`, `secondary`, `ghost`, `danger`, new `quiet`) set vars only.
- Tokens: `--state-hover` and `--state-press` are alpha ink in light and alpha white in dark; values come from owner comparison. The contrast test checks ink on the composited ground.
- Migrate `Button`, `IconButton` (`.cb-ibtn`), `MenuItem` and nav rows (`src/app/shell.css:57-63,333-337`). Replace `src/detail/inspector.css:142-160` with `variant="quiet"`. Ratchet the `hover:bg-n-` count down in `src/styles/theme.test.ts`.

### AFN3-03 — Overlay role pair

## Avoid / doesn't transfer

- **Wholesale Radix / vanilla-extract / next-themes / sonner migration.** Cerebro's `layers.ts` kinds, ghost exits and keymap stand-down are contracts with tests. AFFiNE's own comments show the friction: Radix `modal: true // false will case bug` (`AFC/ui/property/property.tsx`), the pointer-events lock workaround (`AFC/ui/notification/desktop/notification-center.tsx`) and the mobile `onPointerDownOutside` hack (`AFC/ui/menu/mobile/root.tsx`) [read].
- **Two token generations at once.** About 2.9k v1 call sites (`cssVar(`, raw `var(--affine-`) vs about 1.4k v2 [read grep]; the theme editor exposes both trees (`AFX/desktop/pages/theme-editor/theme-editor.tsx`).
