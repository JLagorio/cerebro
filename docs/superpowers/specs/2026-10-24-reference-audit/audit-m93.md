## Risks the references expose

- **Reload-to-recover is common** (4 of the 7 boundary repos reload: Outline, AFFiNE, Morrow, and Activepieces after one retry; Plane, Tolaria and Macro remount instead). Copied, it silently drops Cerebro's memory-only drafts. N01 forbids it and adds a rail test.
- **Three of the save loops studied have a silent-loss path:** Outline's 5-failure cap, AFFiNE's dead loop, Activepieces' halted queue (Morrow's retries with no attempt cap, K01). M93 tests must cover repeated failure, then a later edit, then quit.
- **Memory-only retention is the outlier.** AFFiNE commits each edit to a local SQLite log; Outline keeps Y.js state in IndexedDB (`OL/app/utils/multiplayer/IndexeddbPersistence.ts`). Cerebro's promise ends at a reload (A03), a crash, Dock Quit or logout. Keep the copy and the help that narrow.
- **M93.1 regressed typing cost, unmeasured.** It serializes the whole page on every keystroke. The M93.6 save case (one `insertText` plus the debounce) cannot see it.
- **Lazy materialization trades away a little safety.** An editor crash mid-debounce can lose up to 500 ms of typing unless N01 materializes first. Test it.
- **WKWebView is not Chromium.** Tolaria's ⌘⇧L failed only natively. M93.6 and most e2e run in Chromium (38 specs on WebKit, `playwright.config.ts`), so no number there is native.
- **Reference virtualizers lose access** (Macro, n8n, Activepieces, Plane). Any library candidate must clear REL-08 first.
