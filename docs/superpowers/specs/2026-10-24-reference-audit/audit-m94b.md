## Risks the references expose

- **IME on the shipped engine.** WebKit commits a composition before the Enter `keydown`, so `isComposing`-only guards (M94.4's composers) can create records from IME Enter. jsdom and Chromium tests don't show it (A09, A14).
- **ContextMenu outside the stack.** 10 menus never register a layer: chords run while one is open, and a capture-phase owner beneath (`Popover`) takes their Escape. Their rows can't carry a disabled reason, so M94.5's planned blocker tests cannot pass for them (A02).
- **Vocabulary without a mechanism re-drifts.** "Rename" vs "Rename…" already do different jobs. AppFlowy's 4-vs-136 adoption stall shows that audits without a rail decay (A01, A18).
- **View-level creates bypass M94.4.** QuickAdd and tab-row New skip the IME guard and the destination preview, and they can create records the current filters hide (A13, A14).
- **Moves silently change agent reach.** Grants are folder-scoped, and the move prompt never says who gains write or wake (A05).
- **Missing target resets the origin.** "Go home" contradicts UX-06 (A04).
- **Retry on every errored turn.** If M94.7 restyles it before M95.5 types retry, an unsafe resend becomes more prominent (A20).
- **No render containment.** One throwing section or rail card can unmount the root, and with it the M94.4 session drafts. M93.new-render-containment is proposed, not planned (A27).
- **Reload as an unguarded leave path.** There is no global `contextmenu` policy and no `beforeunload`/`pagehide` (grep). A webview reload would silently drop the session-only drafts. Verify natively (M93.2, M93.11; TDK-04).
- **Loading can mask failures.** A loading state that resolves to "empty" when the read failed repeats Outline's `PaginatedList` failure: an error without `renderError` renders `empty` (`O/app/components/PaginatedList.tsx:284-289`). Loading resolves only to a typed `Read` (A22, A24).
- **Seeding writes values the person didn't type.** Thought Desk seeds from `contains`; AFFiNE seeds from any single condition. Keep A13's narrow rules and the owner gate (D2).
- **One global side-panel state across four panes.** It may surprise multi-pane work (A06, D4).
