> **Verdict: sound with amendments.** The Rust broker, `outcome_unknown` with its unresolved-effect fence, the durable requestKey, validated account binding and Keychain custody match or beat every reference. ## Risks the references expose

- **A fence with no exit.** No reference reconciles a lost create, and GitHub's create has no idempotency key. Without A01, the beta meets "zero implicit repeats" by blocking the repository forever.
- **Outbound MCP is the least proven layer.** The clients are TS (Activepieces MIT, n8n SUL), plus Macro's server-side Rust `rmcp` client (AGPL), which signs in through app OAuth (C01). 2026-07-28 changed the wire model. Remote servers need app OAuth, which the design disables (C01).
- **Compatibility mode is pre-approved by name.** CLI-owned connector tools go out as `--allowedTools mcp__<name>`, and only an 11-name send denylist guards mail (`SECURITY.md:349-380`; `tools.v1.json` `never_call` [read]). Activepieces, by contrast, treats any external MCP tool as WRITE and non-idempotent. A label alone does not fix this; see owner decision 3.
- **Authority held in the renderer.** Approvals stored in localStorage can launch commands (A05).
- **Mutable target names.** `owner/name` changes on rename or transfer, and GitHub redirects the old path (A07; N01 redirect rule).
- **Checks that are off by default rot.** Activepieces 000025's binding check silently lost its thread; keep A04 always on and tested end to end.
- **UI actions turned into agent tools.** Outline's WebMCP registers visible command actions as browser-agent tools (`O/app/hooks/useWebMCPActions.ts:128-138` [read]; OUT1-22, OUT3-23, OUT5-12). It also appends free-text owner guidance to fixed MCP instructions that themselves name tools (`O/server/mcp/index.ts:29-31,105-115` [read]; OUT5-11). M94.5's unified command rows must stay UI-only; tool facts stay in `tools.v1.json` (CV-04/19/29).
- **Absent usage stored as zero** if a second backend ever proceeds (AFFiNE `?? 0`, AFN5-12).
- **Broad imported scope.** gh's token brings full `repo` control into the Keychain (A13).
- **Comments M96.2 will falsify (CV-11):** `connectors.rs:20-22` ("Cerebro still holds no credentials"), `src/app/ConnectorSettings.tsx:29-50` ("Credentials never enter cerebro"), and `SECURITY.md` ("never in Cerebro"). Reword them when a managed connection lands.
