## Risks the references expose

- **Lane-wide breaker coupling.** Failed workflow runs counted in a shared lane trip `ConsecutiveFailures` for every background agent (`runtime/budget.rs:795-800`; counted per lane, `runtime/dispatch.rs:1211-1217`).   > **2026-10-27 (Codex cross-check, status-drift S5; CX-WFC-10):** Superseded: V47 `workflow_run_origins` on `attended_operation` (`runtime/schema.rs:2279`; amendment :16). No CHECK rebuild is needed.

- **Invariants without CV ids.** "A run executes only its pinned version", "preview writes no runtime row" and "a workflow write is a recorded hop" should become CV rules with `enforced:` tests.
