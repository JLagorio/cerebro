## Verdict

- **What Codex adds:** it reconciles with the current tree (backup, restore and the credential bridge now exist), it keeps "declared" apart from "enabled" (dev/canary write tools, the default-off disk sync, a commented-out Zotero), and it gives sharper acceptance lines. It adds few new product items. Its feature catalogue had two we both missed: lazy engines that never retry, and exports that leave attachments behind.
- **Where ours is stale:** BL-113 (a snapshot API now exists), BL-16 ("Rust makes no HTTP call"), BL-78 (the request key has partly landed), BL-116 (a backup manifest with `omitted_scopes` now exists) and BL-34's count. None of our AFFiNE reference claims turned out wrong.
- **Where ours is stronger:** we name concrete Cerebro defects with fixes: the schema-text freeze, SQLite fault injection, the field-identity decision, the turn-scope, submission, untrusted-data and landing contracts, attachment references, and the disk-sync hazards. Codex's AI and storage candidates stop at "retain, adapt degradation".
