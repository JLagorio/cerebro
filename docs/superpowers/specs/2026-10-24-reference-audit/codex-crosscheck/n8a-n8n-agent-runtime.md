## Verdict

- **Codex adds** the n8n agent SDK runtime (sibling call batches, stall liveness, skill rehydration, memory leases, result offload) and the off-by-default failed-run diagnosis pipeline (NAG-33–46). Our audit has none of it, because `delta-n8n` covered only n8n's UI. Codex's M95 native child baseline is also newer than ours.
- **Ours is stale or wrong** in four places. The M95 status line predates the native reservation, the owned claim and restart recovery. BL-74 assumes children can ask the person today, but every CLI subagent ask is already denied in code (`MAIN_ONLY`). The n8n evidence in A02 leaves out that n8n surfaces a child's suspensions one at a time and that a decline cancels the siblings nobody saw. BL-82 reads as wholly open, but its child half is built.
- **Ours is stronger** on chat UX (the retry allowlist, Ask again replay, approval focus, wait vs idle) and on version honesty (BL-13, BL-182). Codex under-credits defences Cerebro already has: nonce fences, the intersect-only skill `narrow`, typed child results, outcome cases that check forbidden effects, and the memory tiers.
