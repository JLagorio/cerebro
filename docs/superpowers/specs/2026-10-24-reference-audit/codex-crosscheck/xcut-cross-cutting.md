## Verdict

- **What Codex adds:** method rather than findings. It has an acceptance criterion on every row, five disposition words (Retain/Adapt/Investigate/Defer/Reject), and "what this does not establish" stated explicitly. A hashed read ledger with drift reconciliation backs a strict declared ≠ enabled rule. It also adds a behaviour-contract UI table and two cross-cutting contracts we lack: capability words (01) and evidence-licensed status words (02).
- **Where ours is stale or wrong:** status tables (README's M98 "no code yet"; CBAR §0/§3; matrix A4/G6/G9/I5/K6) and three backlog premises: BL-16 (no HTTP client), BL-19 (overtaken by a built graph validator; D58 still pending) and BL-113 (no snapshot mechanism). The tree now has M95 archive, M96 transports, M98 runner and M99 backup code, all built but not enabled or accepted. We also counted Outline's edition-gated PDF as shipped.
- **Where ours is stronger:** seven live P0 mechanisms that Codex's priority table never names are all still open today. Ours has two-pass claim verification (1,672 claims vs Codex's 42 sampled paths), 74 owner decisions with options, measured DS roles and per-row licences. Codex's own baseline has already drifted (Settings copy, M98 runner). Several Codex "lessons" are already met by Cerebro and must not become rows (20).
