## Top findings

1. **Ship behaviour-bearing utility primitives, not more tokens.** n8n's settings family fixes rhythm, row anatomy and *save semantics* (instant low-impact vs reviewed draft + save bar; real views commit per field on blur through a serial queue). Cerebro Settings is a page-local `SettingRow` plus literal-px CSS. → Amend M94.2, M94.8.
2. **Setup is a derived checklist.** `N8nSetupPanel` + `setupPanel.types.ts` compute one card per required credential type (consumers, `isAutoApplied`), parameter issues and a terminal Test state. Cerebro has no equivalent. → Add to M96.5, M98.7, M98.9.
3. **Run inspection needs a selection model, not a scroll.** Logs use tri-state `initial|selected|none`: auto-select first error → agent → last, only once stopped; follow identity with run-index fallback; label renamed/deleted nodes. → M98.9 StepInspector, FLOW-07, M95.7.
4. **Mapping must say where a field comes from.** Observed run → last successful run → declared schema (dashed pill, "Usually outputs… / There may be more fields"). Pinned samples apply only in manual/evaluation modes. → M98.9, M98.5.
5. **Retry is an allowlist.** n8n offers Resend for 2 failure classes, last message only, blocked by draft/queue/active turn. Cerebro offers Retry on every errored turn (`src/agent/AiPanel.tsx:1921-1925`). → Amend M95.5.
6. **One layer table.** `APP_Z_INDEXES` becomes `--*--z` vars at boot. Cerebro hard-codes 88/100/1000/1050/1100 in 8+ files. → M94.2.
7. **Don't copy n8n's approval focus.** Autofocus + "Always allow (session)" pre-highlighted + Enter = one-keystroke session grant, and the composer unmounts. Keep Cerebro's explicit buttons and focus return.

### A. Utility composition and save modes (N8N-02, N8N-03)

- `SettingsLayout.vue`: `--settings-content--max-width: 45rem` (L58); `.content > * + * {margin-block-start: 24px}`, `> header + * {48px}` (L107); `fullWidth` lifts the cap for tables.
- `SettingsRow` props: `layout`, `maxDescriptionLines` (clamped 1–3), `actionMaxWidth='50%'`, `actionFill`, `expandable` + `v-model` (mount on first open, keep for exit), `revealActionsOnHover`, `clickable`.
- `SettingsSaveBar`: `visible/saving/saveDisabled/floating/saveShortcut`; `measureStuck()` compares bar bottom with parent content-box bottom → `docked` drops surface/border/shadow; ⌘S ignored when hidden, saving or disabled.
- Field commit (`SettingsPersonalView.vue`): `draft` + `touched`; commit on blur/Enter; `nameSaveQueue = nameSaveQueue.then(saveName)`; the request sends the sibling field at its saved value; email → `pendingEmail` + confirmation modal.
- Cerebro shape: `UtilityLayout` / `UtilitySection` / `UtilityRow` / `SaveBar` in `src/components/`; each field declares `commit: 'instant' | 'reviewed'`. Reviewed fields edit a draft seeded on open (CV-25's rule, generalised); Discard restores; Save calls the existing single writer; failure toasts per CV-03.

### B. Derived setup checklist (N8N-04)

- Data: one card per credential type (`nodes[]` = consumers), per-node `parameterIssues`, trigger card = Test only; `isCardComplete(card)`.
- UI: `SetupPanel` checklist ↔ overlay detail; closing returns focus to `[data-setup-item-id=<previous>]` or the first enabled item; `complete` → collapsed "Setup complete" + Execute.
- Cerebro shape: pure `engine/setupChecklist.ts` over a recipe/workflow definition + M96 account inventory → `SetupItem {id, kind: 'account'|'field'|'trigger', consumers: stepId[], state: 'missing'|'chosen'|'unavailable'}`. No auto-applied account (M96 forbids silent account choice). A failed inventory read is `unavailable`, never "nothing needed" (CV-05).

### C. Run inspection selection (N8N-05)

- `findSelectedLogEntry(selection, entries, isExecuting)`: `initial` + running → none; `initial` + stopped → `findLogEntryToAutoSelect`; `selected` → by id, else same `node.id` at `runIndex-1…0`; `none` → none.
- `useLogsSelection`: `select/selectPrev/selectNext` over `flattenLogEntries`; an external selection expands its ancestors.
- Cerebro shape: pure `engine/runSelection.ts` used by M98.9 step runs and M95.7 child contributions. Auto-select order: first `failed`/`outcome_unknown` step, then first waiting step, then last. Rows label steps removed or renamed in the current draft but stay inspectable from the pinned version.

### D. Field provenance and pinned samples (N8N-07, N8N-08)

- Schema chain in `VirtualSchema.vue`: run data → `previewExecution` → `getSchemaPreview(node)` (cached `Result`); `preview` flag → dashed pill + explanatory copy.
- Pins: `resolvePinData` (manual/evaluation only). Partial runs: `cleanRunData(runData, graph, dirtyNodes)` → `findStartNodes({graph, trigger, destination, runData, pinData})`.
- Cerebro shape: the M98.9 mapping picker lists fields tagged `observed` (a selected recorded run's step output) or `declared` (M96.1 action output schema / step `outputSchema`), drawn differently. M98.5 may preview one step from a pinned sample keyed `(stepId, definitionHash)`; any definition change voids it; runner and admission never read pins. Keep M98's declarative mapping AST, not n8n's expression strings.

### E. Layer table (N8N-01)

- Cerebro shape: `--layer-*` tokens (drag line 88, chord hint 100, dialog 1000, popover/drag ghost 1050, tooltip/toast 1100) in `src/styles/tokens/`; replace literals in `Dialog`, `Popover`, `Tooltip`, `HoverCard`, `ToastHost`, `BlockDrag`, `ChordHint`, `RelationPicker`; a `theme.test.ts`-style rail refuses `z-[n]` ≥ 50 outside the table.

## Avoid / doesn't transfer

- **Approval autofocus + pre-highlighted session allow** (N8N-15): an Enter meant for the vanished composer grants session scope. Conflicts with CV-28/CV-32's deliberate person answer. Never pre-select the widest grant; never take focus from a page editor.
- **Replacing the composer with the approval**: hides Up next and the draft while waiting. Cerebro's dock keeps both (`src/agent/AiPanel.tsx`, `cb-chat-dock`).
- **Expression-string mapping** (`UI/app/utils/mappingUtils.ts` `getMappedExpression` → `{{ $json.path }}`): embedded script. M98 uses a declarative AST; copy only the drag-a-field gesture.
- **Text-matched error classes** (`UI/features/agents/utils/errors.ts` regex on server text): use typed codes (CV-06 already types refusals).
- **HTML in copy** (`DS/directives/n8n-html.ts`: sanitize-html allows `img`): conflicts with CV-61 and "agent text is text, never markup".
- **Silent empties**: the DS README states nine components render empty without `N8nPlugin`, and icons render empty without the loader (dev warning only) [docs]. Cerebro already draws a visible icon fallback (`src/components/ui/Icon.tsx`); keep CV-05.
