## Bottom line

- **Cerebro's write path is the strongest of the 11.** It combines door-minted receipts checked at compile time, per-path locks, compare-before-write for agents, journaled batches and the `outcome_unknown` fence; no reference has all five. Every reference that syncs pays for it with a server or a CRDT. Keep the write path, and import none of that machinery.
- **P0: render faults are uncontained.** Cerebro has 0 error boundaries and a bare `createRoot`. The quit host and the keymap root (hooks) and the job runner (a host component) are mounted inside the tree that can crash. One throw therefore blanks all four panes, ends the ⌘Q save protection (Rust exits 5 s later) and stops wakes. 6 of the 10 references contain faults per section (ARCH-01).
- **P0: the new metadata store is invisible to History, attribution and wakes.** Selected-store writes, live body saves through `save_note` included, record `metadata_receipts` inside the transaction. History, page attribution and CV-48 wake admission read only `vault_writes`. The CV-33 recording rail never scans `workspace_service/`. Fix: relay the receipts by epoch cursor, replay at startup, and keep the relayed kind out of run commits (CV-34) (ARCH-02).
- **P0 before the first real `workspace.db`:**
  - freeze the schema text with a digest (AFFiNE bricked installs with a single whitespace edit) (ARCH-03);
  - decide field IDs vs field names (AFFiNE keys values by property ID) (ARCH-04);
  - measure the per-keystroke whole-page serialization (ARCH-05);
  - treat a webview reload as a leave path (ARCH-06).
- **P1: lifetimes and processes.** Vault state is reset by hand at 36 sites. CV-21 locks work within one process only, and nothing stops a second instance. Fixes: a session object (AFFiNE, Morrow) and one process per installation: the official single-instance plugin (Tolaria and Thought Desk use it; Morrow has an Electron equivalent) or a std `File::try_lock` instance lock (ARCH-07, ARCH-08).
- **P1: plumbing.**
  - `vault-changed` carries no payload and replaces every entry; Outline, AppFlowy and Tolaria all key changes by object.
  - `StoreErrorCode` has 1 variant, and 171 of 234 commands return a bare string error; Outline and AppFlowy use code enums.
  - Background loop failures go only to a log nothing reads; Outline runs a watchdog.
  - (ARCH-09, ARCH-10, ARCH-13)
- **P1: durability of app-private state.** M99 moves metadata out of git. Add, all before activation (ARCH-11, ARCH-12):
  - `VACUUM INTO` snapshots and automatic rolling snapshots (AFFiNE, Morrow);
  - a backup tier for each of the 58 `cerebro.*` localStorage keys;
  - SQLite fault injection that runs in-process on a Mac.
