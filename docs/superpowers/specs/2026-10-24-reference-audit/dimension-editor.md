## Bottom line

- **Keep the model.** Markdown is the truth, and CV-24 means every block Cerebro offers has a carrier. The JSON- and CRDT-first references (AFFiNE, Outline, Macro, Plane, AppFlowy, Thought Desk) all lose content on Markdown export. Morrow and Tolaria, the other two Markdown-first editors, have converged on Cerebro's shape.
- **P0, before M93.1 commits:** the uncommitted M93.1 owner wiring serializes the whole page on every keystroke. HEAD does not. Five references serialize only when they save. Add a typing workload to M93.6; if it shows the cost (ARCH-05 and M93-A01 gate on the same measurement), make `edit()` a generation bump plus a materializer (EDIT-01).
- **P0, also current work:** M97.2's narrow mapper, which mention insertion reuses (EDIT-11); an editor render boundary that keeps the owner and ⌘Q alive (EDIT-14, with `M93.new-render-containment`); and the WebKit IME Enter guard on M93.2's new `FocusedFieldInput` (EDIT-12).
- **Three carrier gaps, all verified in code:**
  - A `cerebro-database` fence drops extra keys and comments, and the page then opens read-only (EDIT-03).
  - ⌘U, and pasted `<u>`, coloured spans, alignment or block colours, set styles or props that the save drops (EDIT-04).
  - Enter inside a table cell inserts a line break that GFM writes as a space (EDIT-04).
- **Converge where the references agree:**
  - Keep carriers in a table rather than central lists (5 repos, EDIT-05; P2, no defect needs it).
  - Draw editor menus with the app's own components (all 8, EDIT-10; P2, a consistency gap).
  - Remember folded toggles per viewer, under a key that survives reopening (Outline only; EDIT-09).
- **M97.2 lands only on plain pages.** Its second grammar refuses any mark, link or table. Derive the position map from the serializer instead, as Outline does (EDIT-11).
- **Optional, owner-gated:**
  - keep the original bytes of blocks a save did not touch (Outline);
  - math (7 of 8 references have it);
  - `==` and `<u>` carriers;
  - a portable export dialect;
  - raw HTML "kept as written" instead of locking the page.

Lessons:

- **Carry an effect on every route that can produce it:** menus, keys, paste and table keystrokes. Morrow gets there by carrying every mark it offers. Cerebro withholds the menus but not the keys (EDIT-04).
- **Keep bytes you cannot edit.** An atomic verbatim block (Morrow), or verbatim props (AFFiNE; Cerebro's sheet and board), is better than a pointer rebuilt from parsed props or a locked page (EDIT-03, EDIT-06).
- **Separate the edit from the normalizer** by comparing against a round trip of the original (Outline). That gives one-block diffs (EDIT-07).
- **Portable HTML carriers** (`<details>`, `<div data-columns>`) render in other apps (Morrow, AppFlowy). Keep Cerebro's Obsidian-style carriers in files, and offer a portable export (EDIT-21).
- **A version stamp needs a reader.** AFFiNE stamps versions that nothing migrates. M99.8 already requires old-reader import for its sheet-header codec; hold every versioned carrier to that rule.
- **Golden cases come before new syntax:** AFFiNE's currency and escaped-dollar cases come before `$` math.

## Where Cerebro is ahead (keep)

- **CV-24 is enforced by walking the real builders.** The tests walk the `/`, toolbar and block-menu builders (`markdown.test.ts:1279,1534`, with `KNOWN_LOSSY` empty), plus a WebKit e2e (`e2e/editor-carriers.spec.ts:98`). No JSON-first reference limits itself to offering what it can keep.
- **Opening never writes** (the `lastEmitted` baseline, `MarkdownEditor.tsx:836-840`). A lossy page names its cause and opens read-only. Outline's repair-on-first-edit and Morrow's unknown-content lock follow the same rule.
- **Pointer fences (D7), not rows embedded in the document** as AFFiNE does with database children and AppFlowy with its CSV export.
- **The title is the first H1, in the same editor, undo history and file** (`pageTitleProjection.ts`). Tolaria converged on this; AFFiNE, Outline and Plane keep a second title store.
- **Comments live in a sidecar, with an occurrence and an explicit detached state** (`src/engine/commentAnchor.ts`, CV-31). Outline, AFFiNE and Macro put marks in the content, and Outline takes the first match.
- **`DocumentOwner` keeps drafts above the presentation** (`documentOwner.ts`, class `DocumentOwner`; cited by symbol because the file is under active edit). Morrow has one global queue, and Tolaria repairs lossily.
- **Block drag uses pointer events the test harness can drive** (`MarkdownEditor.tsx:314-358`).
- **The AI rewrite never streams into the buffer** (`AskAiPopover.tsx`); AppFlowy streams into the document.
- **Find matches chips by their label, never replaces inside links, and replaces in one undo step** (`findMatches.ts`).
- **The prose diff works by block and word, from Markdown** (`proseDiff.ts`); Morrow diffs by line.
- **Syntax stays Obsidian-compatible:** `> [!kind]`, `![name|300]`, `[[…]]`, `[^id]`. Outline uses `__` and `mention://`; Macro writes XML elements.
- **JSON Canvas keeps unknown values and key order** (`src/engine/scene/model.ts:24-25`, CV-55).
- **Marker lookalikes are escaped, not swallowed** (`escapeMarkerLines`, `markdown.ts:1138`).

## Avoid

- **JSON or CRDT as the body's authority** (AFFiNE, Outline, Plane, AppFlowy, Macro, Thought Desk). It forces the loss list above.
- **Comment marks, authorship and JSON footnotes stored in the content** (AFFiNE, Outline, Macro). They break CV-31 and CV-35.
- **An iframe embed registry** (Outline) or a remote HTML preview (AFFiNE). Both conflict with CV-16 and CV-61.
- **Live, editable embeds of another file** (Morrow mounts `![[database]]` and `![[canvas]]` editable, `MR/app/editor/PageEditor.tsx:42-64`). An editable embed is a second live editor on a file another pane may hold, which breaks CV-52. AFFiNE's synced doc (a `readonly: true` store, `AF/affine/blocks/embed-doc/src/embed-synced-doc-block/embed-synced-doc-block.ts:415-419`) and Morrow's page embeds are read-only.
- **Lossy render repair** (Tolaria `blocksToHTMLLossy`). It conflicts with CV-24.
- **Smart typography on by default** (Outline SmartText, `OL/app/editor/extensions/index.ts:16-22`; Thought Desk `Typography`, `TD/editor/extensions.ts:137`). It silently changes bytes that agents grep.
- **`content-visibility` rows** (Thought Desk). REL-08 bars them unless offscreen accessibility is proven.
- **First-match patching and anchoring** (Outline). Weaker than `occurrence` and KNOW-02.
- **Serializing eagerly on every update** (Plane; Macro's collab surface). Cerebro's M93.1 has joined them; EDIT-01 reverses it.
- **Streaming AI text into the live document** (AppFlowy).
