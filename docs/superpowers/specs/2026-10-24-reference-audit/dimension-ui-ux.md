## Bottom line

- **Cerebro's parts are ahead; its journeys still end badly at the seams.** One keymap, five read states, explicit layers, pane container queries, first-H1 titles, an offered starter kit and search → passage → Return all beat every reference (see Keep). Import no shell and no design system.
- **One render throw blanks all four panes** and unmounts the ⌘Q flush listener (0 boundaries in `src/`). M93.1's retained owners keep unresolved drafts in memory (`src/editor/openPages.ts:400-407`), but nothing is left to show, retry or flush them. 7 of 10 references contain faults per region (Macro too). → P0, `M93.new-render-containment`.
- **Journeys dead-end:**
  - a trashed or missing page offers only "Go home", on 3 surfaces; 4 references restore in place;
  - a failed search can't become a page (AFFiNE, Tolaria);
  - a dangling `[[link]]` can't become a page on click (Morrow); typing `[[` already can (M55.7);
  - a record created in a filtered view can vanish (AFFiNE, Thought Desk).
  → M94.4–M94.6.
- **The native shell is unowned:**
  - ⌘W quits the app, by design (`src-tauri/src/shell/mod.rs:15-16`);
  - there is no Settings… ⌘,;
  - there is no app zoom: the browser stand-in (root CSS zoom 2) leaves the shell's media queries at full width, and the "real zoom" that the program design, PROG-T02, M94.3 and M94.9 require has no mechanism;
  - the window ignores the theme and forgets its frame;
  - webview Reload is an unguarded leave path.
  → P0 decisions plus `M94.new-native-shell`.
- **State memory is too global or too short.** Details/Comments/History is one value shared by every pane, and it remounts on each switch; Outline keeps it per split pane and mounted, and Plane keeps the tab in the URL so Back restores it. Loading is a line of text, not geometry (5 references).
- **Menus have no shared vocabulary.** 10 hand-written ContextMenus sit outside the layer stack, while 5 references draw every menu from one action row. M94.5 already plans the shared vocabulary (PJ08); the layer join is the P0 → M94.5.
- **Totals:** 38 rows (6 P0, 20 P1, 12 P2; UX-01's P0 covers only its root hook, quit host and pane/peek/editor boundaries). 7 add provisional phases; 27 amend existing ones; 4 confirm work the plan already holds (UX-03, UX-07, UX-13, UX-28). 16 keeps, 14 cuts.
