## Keep track of where a copy came from

For a Notion page, ask the assistant to fetch the page through your approved connector and import it into a folder you name. The import uses the fetched result and records its source. Notion databases are not part of this page importer.

Read the import result before continuing. Unsupported or incomplete material may require a composed copy, which is marked as composed by the assistant. Check its formatting and links against the original.

## Import the same page again

An unchanged imported copy can be updated in place. A copy you edited is left alone; the result explains that it was preserved. Moving the copy does not remove its source identity. Do not delete your edited copy just to make an update proceed: compare the versions and decide what you want to keep first.

CSV and spreadsheet imports are separate import flows. Review their destination and any reported conversion losses. Choosing a file does not create a page; the explicit Import action does. Check the new page before relying on converted formulas or values.

Fetching connected material can also create a local working source copy, separately from importing an editable page. Review source and mail settings before requesting private material. Granting connector access does not import every document in that account.
