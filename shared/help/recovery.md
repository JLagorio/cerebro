## A page could not save

Keep the page open and read the failure message. Retry saves the retained draft without requiring another edit. A navigation or quit request may stay on the page until the save succeeds or a conflict is resolved.

If another app changed the page, review the reconciliation choices before deciding which text to keep. A deleted target is not recreated automatically. Keep a separate copy of important text before closing a failed editing session.

Unsaved drafts retained by this session are not a backup after a crash, logout or process exit. Page History shows recorded Git versions when available. Settings → Recently deleted can restore files removed through Cerebro's Trash, provided the destination is free. Outside deletions and uncommitted outside edits may not have a recoverable version.

## The assistant is unavailable

Open Settings → Assistant and inspect the Claude Code status. Cerebro uses your own installed Claude Code and its sign-in. If a run specifically says you are not signed in, open Claude Code in Terminal and use /login there. An unsuccessful status check alone does not establish that the program is missing or that you are signed out.

## A connector is unavailable

Inspect the connector in Settings → Assistant. Check the account, connection and selected tool permissions. An unavailable inventory does not prove an existing grant is absent. Use Retry where offered and inspect the result before changing saved permissions.

Do not paste passwords or secret tokens into a page or conversation to repair a connection. Use the connector's own connection flow. A successful connection check does not mean a previously failed action ran; inspect its result before trying it again.
