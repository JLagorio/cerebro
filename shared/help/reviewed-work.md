## Give an agent a small, clear task

Start with a disposable page or a small folder. Open an agent from the Library, read its Instructions, and check its properties before running it. New agents start paused.

Choose the folders it may read and write, the tools it needs, and whether it must ask before making changes. Connector access is a separate grant. Give it only the access needed for the task, and save the property changes with Done.

## Supervise the result

1. Once you have checked its instructions and permissions, use Resume on the agent's page. A paused agent cannot be called.
2. Tell the assistant what outcome you want, which agent should do it, and which page or folder is in scope.
3. When it asks a question or requests approval, read the proposed action and its target before answering. Declining leaves that action unapproved.
4. Open the agent's Runs tab to inspect recorded work. Follow the changed pages and check the actual result.
5. Pause the agent again after the supervised task if you are not ready for further scheduled or triggered work. Pausing is not an undo of completed actions.

Some requests wait in Knowledge → Review under Waiting on you when nobody is watching. A queued request is not a completed change. A failed or interrupted run may have made earlier changes, so inspect the recorded work before trying again.

For mail, ask for a draft you can review and send yourself. The shipped Draft reply recipe needs an approved Gmail connector and does not send mail.
